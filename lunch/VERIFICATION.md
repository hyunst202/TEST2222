## 자동 검사

`test_app.py`: **12개 검사 통과**.

- 한국어·영어 화면, CSS 제공, 화면에 직접 작성한 JavaScript 없음.
- 시간·예산·음식 종류·식사 취향·매운맛을 함께 적용.
- 20분 점심에 가능한 후보 제공, 왕복 이동·대기 시간 포함.
- 완전 채식 선택에서 달걀·유제품 메뉴 제외.
- 이동·대기가 길어지면 후보가 줄거나 없어짐.
- 후보 없음 안내, 조건을 몰래 완화하지 않음.
- 뽑기 결과가 조건에 맞으며 다른 후보가 있으면 직전 메뉴 제외.
- 후보가 하나일 때 뽑기 정상 처리.
- 재추천 링크의 조건 유지, 한영 메뉴·주문 문장·외부 식당 검색 링크.
- 조건을 벗어나는 메뉴 결정 404, 잘못된 입력 422.
- 여러 번 초기화해도 메뉴 18개, 테이블 하나, 관계 없음.
- 상태 확인과 API 문서 응답.
